# Community Pools LLC — Website

Responsive website for Community Pools LLC, a swimming pool service company based in Port Charlotte, FL.

## Stack
- Plain HTML, CSS, JavaScript — no build tools required
- Hosted on Netlify (connected via GitHub)
- Netlify Forms for quote/inquiry submissions

## Deploy
This repo is connected to Netlify. Every push to `main` automatically redeploys the live site.

## Structure
```
/
├── index.html          # Main site
├── styles.css          # All styles
├── script.js           # Slideshow, sliders, mobile nav, form
├── netlify.toml        # Netlify config & cache headers
└── assets/             # Images, logo, favicon
```

## Forms
Quote inquiries are captured via Netlify Forms. Log in to the Netlify dashboard → Forms to view submissions and configure email notifications.
